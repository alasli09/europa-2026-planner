> [!CAUTION]
> **ALERGIA SEVERA: MANÍ / CACAHUETES / PEANUTS**
> - **España:** Maní / Cacahuetes
> - **Italia:** Arachidi
> - **Francia:** Arachides
> *Riesgo de anafilaxia. Preguntar SIEMPRE en restaurantes e inspeccionar etiquetas. Llevar medicamentos / Epipen a mano.*

> [!NOTE]
> **PREFERENCIA ALIMENTARIA (NO ALERGIA): CAMARONES / MARISCOS**
> - No le gustan los camarones por preferencia personal, pero **no** presenta reacción anafiláctica.

> [!TIP]
> **CLIMA Y LUZ EN NOVIEMBRE**
> - **Frío otoñal:** Temperaturas promedio entre 5°C y 14°C. Vestir en capas (térmicas, suéter, abrigo cortavientos/impermeable).
> - **Días cortos:** El sol se oculta entre las **17:00 y las 17:30**. Iniciar las actividades al aire libre temprano (08:30 - 09:00).

## 📱 Cómo Utilizar este Repositorio en el Viaje

1. **Dashboard en el Celular:**
   - Habilita **GitHub Pages** en la configuración del repositorio (`Settings > Pages > Deploy from a branch > /docs`).
   - Guarda el enlace en la pantalla de inicio de tu iPhone / Android para acceder como una app nativa.
2. **Actualización de Gastos al Instante:**
   - Edita directamente el archivo `docs/data.js` en GitHub móvil o en web.
   - Agrega tu compra en el arreglo `expenses`:
     ```javascript
     { fecha: '2026-11-03', concepto: 'Almuerzo tapas Sol', categoria: 'Comida', cop: 120000, eur: 30, pagadoPor: 'Alan', metodo: 'Tarjeta' },
     ```
   - El dashboard recalcula automáticamente los totales, gráficos y porcentajes.
3. **Consulta Offline:**
   - Puedes clonar o descargar el repo en la app de GitHub / Obsidian / visor de Markdown en el teléfono para ver los archivos `.md` de itinerarios sin conexión a internet.
